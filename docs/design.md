# Design

## Product character

StrengthLog should feel energetic and fast without adopting the dense, black-and-neon look common to lifting apps. The visual system uses a deep navy foundation, electric coral actions, mint completion states, soft grouped backgrounds, and rounded cards.

## Interaction principles

- Live logging optimizes for one-handed taps between sets.
- The brand hero belongs to the welcome step. Workout presents up to three routines under Quick Start with an All Routines path, the four-week activity card second, and a conditional Deleted Workouts link last.
- Onboarding offers three unselected starter-routine cards after people setup; continuing without templates is equally prominent.
- An active exercise uses a compact matrix: up to three participants use the same fixed column width as the three-person layout and fill from the left. Participant names and badges are omitted inside exercise cards; the profile colors on Load, Reps, menus, and completion controls identify each column. Participant Load controls are followed by participant Reps controls with an optional last-set menu and numbered completion squares, then shared set actions at the bottom.
- Routines are person-agnostic and contain exercise structure only; weights, reps, and sets are configured per person from the latest workout.
- Starting a workout defaults to its most recent crew. People can be toggled on and off quickly; turning off someone with completed sets warns first and keeps their data available if they are turned back on. The pinned picker omits a redundant People label. At the first exercise it retains the roomy, natural-width name pills; after advancing or scrolling down, it compacts into the same fixed 108-point columns and spacing as the Load/Reps matrix, centers each person over their controls, and truncates long names with an ellipsis.
- Completion is tracked per set and per person with numbered squares whose profile-colored outline and light fill communicate that the next sequential set is tappable; later unavailable sets stay subdued. Undoing a square preserves the planned sets.
- Measurements and base reps combine keyboard-editable numeric fields with large minus/plus targets; measurement fields have a visible border. Changing base reps updates ordinary sets while preserving a customized last-set override. New workouts show only completed historical sets, equalized across the group, and people without completed history use the configurable default of eight reps.
- Large Remove Set and Add Set controls close each exercise card, in that order, and change the shared set count for everyone; Remove Set is disabled at one set, and the next-exercise arrow has a distinct trailing margin. Reps labels use singular Rep when appropriate. Larger Load and Reps values and the midpoint of each two-wide row of numbered completion squares share one vertical axis. Participant rep controls stay on the same horizontal line when one participant has multiline customized/skipped status or fewer active completion rows; status occupies a shared-height row, leaving compensating whitespace beneath the other participants' ellipsis controls before the shared completion row continues. Completion squares wrap after two columns in every participant mode. Circular minus/plus controls and an enlarged ellipsis menu provide consistent, generous tap targets. Each participant's ellipsis action offers Customize Last Set, Skip Last Set, and Skip Last Two Sets when enough active sets remain; customized/skipped status is multiline and recoverable.
- Single-sided exercise names show concise rep-count semantics—per side for one-arm/one-leg movements and total split evenly for alternating movements—without separate L/R counters.
- One chart action in the exercise header shows every active participant's measurement and best-rep lines in their profile colors.
- A filled orange next-exercise arrow sits at the bottom-right of the final shared set-action row. It advances without changing any exercise checks. Complete Workout retains the full-width treatment at the end of the session. Completed set squares receive participant-colored completion styling.
- Each exercise name appears in its card, and the navigation title always reflects the explicit current exercise target rather than the most recently scrolled-off card. The People picker stays pinned directly beneath that title while exercise cards scroll. The orange up arrow is absent on the first exercise and appears only when a previous exercise exists; each exercise card owns its own orange down arrow for advancing. Programmatic navigation keeps an explicit current-exercise target so down/up reverses exactly and repeated down/down/up lands on the middle exercise. Reopening scrolls after the furthest exercise with at least two completed active-participant sets, or to the first exercise when no meaningful progress exists.
- Exercise thumbnails are visible in the workout; tapping one opens a full-size, swipeable position gallery.
- An open workout becomes a distraction-free app root with no tab bar; Done restores normal navigation. Tapping an exercise name pushes its detail screen without adding an edit button to the workout. Unit and rep-counting edits there apply immediately on return. `perSide` exercises show Reps/side and explain that 8 means 8 on each side, with one completion tap after both sides. Timed exercises show a single duration control, not load plus reps.
- Routine lists expose standard edit-mode reordering. Routine edit mode exposes name, exercise addition, and a dedicated appearance sheet with a curated icon and color grid, plus a bottom destructive action, while hiding Start Routine. The sheet remains interactive while the exercise list is in reorder mode. Exercise addition, deletion, reordering, and appearance changes refresh the draft immediately but persist only through Save; Cancel restores the stored routine. Routine deletion moves it out of active views into Deleted Routines, which appears as a conditional link at the bottom of the Routines list and offers an explicit Restore action.
- Participant selection happens when starting and can be changed from the live screen without deleting hidden data.
- Reorder and Add Exercise use compact secondary controls in the scrollable footer of an open workout. Participant selection stays in the pinned picker beneath the current exercise title, and selected pills use each person's profile color.
- Reorder pushes a dedicated screen with compact numbered exercise names and native drag handles. It omits images, participant controls, and set editors so typical workouts fit on one screen; long names wrap and longer lists remain scrollable. Order changes stay in a local draft until Save succeeds. Cancel leaves the saved order untouched; a save failure keeps the draft visible and reports the error. Reordering never changes the routine or any logged set data.
- Workout logs save continuously. Close is lightweight navigation, and reopening is immediate; neither requires confirmation.
- Each routine may define one shared optional rest duration. Completing a set starts that countdown, and the active workout keeps only the rest row pinned beneath the title while a countdown is running; the countdown replaces the exercise title and elapsed workout length sits above Complete Workout. The Workout home card also shows the active rest countdown. Workout length is recorded from start to the latest completed set, continues ticking while an open workout is active, and is shown in active status and history details. Rest expiry provides an audio alert, an opt-in local notification, and an ActivityKit Live Activity for the Lock Screen and Dynamic Island; the Lock Screen activity includes the current exercise, set progress, reps, and load.
- Completing a workout opens a dark, celebratory summary screen with a party-pop icon, short encouraging message, the routine/date, total volume and duration, then one profile-colored card per participant. Each card shows completed sets, pounds volume, and any new personal records. A four-week momentum section shows workout count and pounds volume per person. A single bottom action returns to Workout home.
- Workout history supports swipe-to-delete from Progress, plus confirmed delete actions from session details and the bottom of an open workout. Deleting a workout removes it from the calendar and activity counts but never removes its routine or catalog exercises; the conditional Deleted Workouts link on Workout supports restoration.
- The activity card uses a Sunday-through-Saturday calendar with a weekday header and exactly four compact week rows. Previous and next controls page in four-week increments, stopping at the current four-week period. Boxes omit day numbers, use each routine's configured symbol and color when available, fall back to a short acronym when no symbol is configured, add a count badge for multiple workouts on one date, and show a small two-person glyph when more than one person participated that day. Deleted workouts are excluded. A single-workout day opens that workout directly. A multi-workout day first opens a compact picker showing each routine icon and name, then time, people count, and completed-set count on separate icon-free lines; selecting a row opens the same single-workout detail. Detail renders completed sets only and omits exercises or people with no completed sets. Every detail keeps its trash icon in the top-right, returns to Workout home after deletion, and uses centered, caret-free confirmation alerts whose deletions remain restorable. Completed-set glyphs reuse the active-workout check styling at a smaller size and use the recorded person's color. When the selected workout has unfinished sets, one action at the bottom presents the same centered confirmation alert and removes its unfinished sets.
- CSV import begins with routine selection. The complete exercise list then filters to those routines, defaults to frequency order, can be sorted by recency or name, and can be displayed for all history or the last 30, 60, or 90 days relative to the newest selected workout. The display filter does not change import scope. Each exercise opens a name-only searchable mapping override with explicit skip and create-custom options.
- Exercise search matches exercise names only. One compact filter menu presents All, Custom, then an alphabetical Main Muscle section. The editor names the workout value each set logs, keeps Main Muscle and Equipment visible, moves descriptive Exercise Type into More Details, and explains that muscle drives filters, equipment aids display and import matching, and type is descriptive only.
- Progress exposes one compact duration menu with 4W, 12W, and All time choices. Training Volume is a person-separated line chart with dots at each recorded session, and the duration choice filters both the chart and workout history.

## Accessibility

- System type supports Dynamic Type.
- Status is conveyed with both symbols/text and color.
- Participant badges expose full-name accessibility labels.
- The activity calendar exposes date, workout count, routines, and multi-person participation per cell.
- Controls use standard SwiftUI button, picker, stepper, and text-field semantics.

## App icon

The master is a 1024×1024, high-contrast dumbbell monogram with no text or baked corner mask. Its teal `L`-shaped left weight and `C`-shaped right weight embed the Lift Chase initials into the lifting geometry, while the connecting shaft and mirrored outer plates remain electric coral against a deep navy background. The compact mark has an uninterrupted shaft, natural dumbbell proportions, and a bold silhouette that remains recognizable at 40–60 px.

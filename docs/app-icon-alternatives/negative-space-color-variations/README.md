# Negative-Space Load color variations

Generated with the built-in image editing tool as 1024 x 1024 opaque PNG masters.

## Shared geometry prompt

- Start from the selected Negative-Space Load concept.
- Remove the teal center square/collar and replace it with an uninterrupted shaft.
- Shorten the exposed shaft so the `L` and `C` sit closer together with compact dumbbell proportions.
- Mirror the conventional plate hierarchy: moving outward from either letter-shaped weight, use one taller inner plate followed by one shorter outer plate.
- Preserve the integrated `L`-shaped left weight, `C`-shaped right weight, slight upward tilt, deep navy background, bold rounded geometry, generous safe margin, and small-size legibility.
- No text, additional symbols, watermark, device mockup, or baked rounded corners.

## Color prompts

1. **All Orange** — Recolor the entire dumbbell—`L`, shaft, `C`, and all four conventional plates—electric orange/coral.
2. **Teal LC** — Make the full `L` and `C` teal; keep the shaft and conventional plates orange.
3. **Orange LC** — Keep the full `L` and `C` orange; make the shaft and conventional plates teal.
4. **Teal Plates** — Keep the `L`, shaft, and `C` orange; make only the four conventional plates teal.
5. **Split LC** — Make the `L`, left plates, and left half of the shaft orange; make the `C`, right plates, and right half of the shaft teal, joined at a crisp midpoint seam with no gradient or connector.

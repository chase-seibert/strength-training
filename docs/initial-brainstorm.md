# Initial brainstorm

The project began from a spoken product brief for a new iOS strength-training app. The requested experience was:

- Configure reusable routines such as upper body, lower body, and core, each with any number of exercises.
- Model exercises with sets/reps and an editable exercise-level measurement such as pounds, steps, distance, or time.
- Crowdsource up to roughly 1,000 popular exercises, infer suitable measurement units, and research open illustrations, photos, or video showing form.
- Permit custom exercises and edits to catalog exercises.
- Run only one timed routine at once; check off sets; edit load/reps and add sets during the routine; finish exercises or the whole routine with incomplete sets.
- Keep a visible count of remaining exercises/sets, preserve unfinished data, and allow an accidentally finished workout to be resumed.
- Save complete historical session snapshots and use the latest set/rep/measurement configuration as the next defaults.
- Show a 30-day activity calendar and pounds-only volume line charts for a routine.
- Track one shared routine for a configurable group—initial examples were Chase, Henry, and Owen—with different measurements and progress per person.
- Let the user quickly choose the day's participants and hide everyone else.
- Optimize repeated sets into one compact row per exercise/person with separate one-tap set checkboxes and a quick add-set control.
- Produce both an exercise-source research report and an initial working version of the app.

This document is a lightly normalized transcript preserving the requirements and examples from the original spoken prompt.
